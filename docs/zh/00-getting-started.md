# 00 快速开始

目标:十分钟内,让 Codex 读懂你的一个项目,并做一件小事。

## 1. 安装与登录

Codex 有命令行(CLI)、IDE 插件和网页等多种入口。具体的安装命令和登录方式更新很快,
请直接看官方文档,不要依赖二手教程。

- 官方仓库与文档:https://github.com/openai/codex
- 登录通常有两种思路:用账号订阅登录,或者用 API Key 按量计费。两者的区别见 [04 模型选择与价格](04-models-and-pricing.md)。

> 最后核对日期:待填写

## 2. 第一次使用:只读探索

在一个**已经用 Git 管理**的项目目录里启动 Codex,第一句话不要让它改东西,先让它读:

```text
请阅读这个仓库,告诉我:
1. 项目是做什么的
2. 主要目录和入口脚本
3. 怎么运行测试
先不要修改任何文件。
```

这样做有两个好处:你能马上看出它有没有理解对,也能发现项目里哪些约定还没写清楚。

## 3. 第一次改动:小而可验证

挑一个小任务,例如"给 `scripts/clean_ligands.py` 补上 docstring 和类型标注",并且要求:

- 先说明打算改哪些文件
- 改完运行现有测试
- 不要改动 `data/` 下的任何内容

然后用 `git diff` 自己看一遍。习惯从第一天养成。
