# AGENTS.md

> 复制到你项目的根目录,按实际情况修改。保持简短、具体。

## 项目简介

一句话说明项目做什么。例如:用于筛选 BRD4 配体的对接与打分流程。

## 环境

- 创建环境:`mamba env create -f envs/environment.yml`
- 激活环境:`mamba activate <env-name>`
- 运行测试:`pytest -q`

## 目录约定

- `data/raw/`:**只读**,任何情况下不要修改、移动或删除
- `data/processed/`:由脚本生成,可以重新生成
- `src/`:可复用代码
- `scripts/`:入口脚本,保持精简,逻辑放在 `src/`
- `tests/`:使用 `tests/data/` 下的小样例
- `results/`:可再生输出

## 禁区

- 不要修改 `data/raw/`
- 不要提交密钥、`.env`、大体积数据或模型权重
- 不要在未说明的情况下新增依赖

## 代码风格

- Python 3.x,使用类型标注
- 格式化与检查:`ruff format` 与 `ruff check`
- 函数要有 docstring,写清输入输出和单位

## 工作方式

- 较大的改动,先给出计划,等我确认后再动手
- 一次只做一件事,改动尽量小
- 改完运行测试;测试不通过不要说"已完成"
- 完成后简要说明:改了哪些文件、为什么、如何验证

## 完成标准

- 测试通过
- 没有改动禁区内的文件
- 新增或改动的函数有 docstring
